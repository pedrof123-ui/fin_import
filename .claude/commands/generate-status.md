# generate-status

Use this command prompt to summarize implementation status.

## Prompt template

```text
Read CLAUDE.md, ACTION_PLAN.md, AGENTIC_TEAM_FRAMEWORK.md, and REVIEWER_APPROVAL_CRITERIA.md.

Use the orchestrator agent.

Generate a concise implementation status report.

Include:
1. Current phase
2. Completed phases
3. Pending reviews
4. Blockers
5. Files changed so far
6. Tests run
7. Remaining risks
8. Next recommended step

Do not modify code.
```
